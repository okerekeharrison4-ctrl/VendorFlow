# Branding Guidelines

## Colors
- **Primary**: Deep Pine Green (`#2A7A3E`) indicating trust, money, and professionalism.
- **Surface**: Minimalist white/gray scaling for light mode, deep slate for dark mode.
- **Typography**: Inter (Sans-serif) for clean readability.

## Visual Identify
- No excessive borders; use ambient shadow drops.
- Pill-shaped buttons (`rounded-full`) for primary actions.
