# Branding Guidelines (Brand Book)

## 1. Brand Identity
**Name:** VendorFlow
**Mission:** To make professional invoicing accessible, fast, and secure for every micro-business and freelancer, anywhere in the world.

## 2. Logo & Iconography
* **Primary Logo:** A clean, modern SVG icon representing flow and commerce (e.g., a stylized receipt or checkmark).
* **Iconography:** Lucide React icons. Stroke width should consistently be set to `2` or `2.5` for a bold, readable look.

## 3. Color Palette
VendorFlow uses a dynamic, themeable color system (Light and Dark modes).
* **Primary:** Blue/Indigo hues (e.g., `#2563eb`) used for primary actions (Save, Share, Upgrade).
* **Surface/Background:** 
  * Light Mode: Clean whites and light grays (`bg-surface-container-lowest`, `bg-surface-container-low`).
  * Dark Mode: Deep grays and blacks for OLED-friendly dark mode.
* **Semantic Colors:**
  * Success: Green (`#16a34a`)
  * Error/Destructive: Red (`#dc2626`)
  * Warning: Orange (`#ea580c`)

## 4. Typography
* **Primary Font:** `Inter` (or system sans-serif fallback). Used for all UI elements, buttons, and general text.
* **Monospace Font:** `JetBrains Mono` or system monospace. Used strictly for financial figures, invoice numbers, and tabular data to ensure vertical alignment (`tabular-nums`).
* **Template Fonts:** Specific templates may use serif fonts (e.g., Elegant template) or heavy sans-serifs (e.g., Bold template) to differentiate styles.

## 5. UI Styling
* **Border Radius:** Heavy use of rounded corners (`rounded-3xl`, `rounded-full`) for a friendly, modern mobile app feel.
* **Shadows:** Soft, ambient shadows (`shadow-ambient`) to create depth without harsh lines.
