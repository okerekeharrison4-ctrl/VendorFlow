# Product Requirements Document: VendorFlow

## 1. Product Vision
VendorFlow is a minimal, elegant invoice and catalog management tool built for freelancers and small businesses. It enables users to quickly create, send, and track invoices, manage client relationships, and maintain a lightweight product/service catalog.

## 2. Key Features
- **Cloud Sync & Authentication**: Secure Google Login powered by Firebase Authentication. Real-time data sync across devices.
- **Invoice Generation**: Create, customize, and export professional PDF invoices.
- **Client Management**: Save and reuse client details (name, email, tax ID).
- **Catalog System**: Manage standard products and services for 1-click invoice additions.
- **Security Protocols**: Zero sensitive data stored in accessible LocalStorage; robust Firestore security rules with strict access verification.

## 3. Platform Support
- Web-first (responsive layout for Desktop and Mobile via Tailwind CSS).
- Installable PWA.
